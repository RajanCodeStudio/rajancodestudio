lock

3. Android System Permissions

To perform core network switching and display accurate cellular signal statistics, our application requests specific Android system permissions:

wifi

Network & Wi-Fi State

INTERNET, ACCESS_NETWORK_STATE: Required to detect internet connectivity and active network types (4G / 5G / Wi-Fi).

signal_cellular_alt

Cellular & SIM State

READ_PHONE_STATE: Required to display mobile carrier name (e.g., Jio 5G, Airtel 5G) and current signal strength levels.

location_on

Location Permission

ACCESS_FINE_LOCATION: Mandated by Android system architecture to read cell tower information and Wi-Fi SSID details. We never log or track your GPS location.

extension
